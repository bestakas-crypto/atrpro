--------------------------------------------------------------------
1. 기술 스택
--------------------------------------------------------------------
- 서버: Python 3.12, FastAPI, uvicorn(단일 워커), 표준 sqlite3 + 얇은
  Repository 계층, httpx (KIS 클라이언트/텔레그램 클라이언트)
- 프런트엔드: 순수 HTML/CSS/JS (ES Modules), 빌드 도구 없음, 기존 라이트
  테마 유지, PWA(manifest.json + service-worker.js)
- DB: SQLite (WAL, foreign_keys=ON, busy_timeout=5000, synchronous=NORMAL)
- 프로세스 분리: 웹(main.py)과 시세 Worker(worker.py)를 별도 프로세스로
  운영, 같은 SQLite DB만 공유 (외부 웹훅/localhost HTTP 호출 없음)
- 로컬 개발 환경: conda env "strpro" (Python 3.12), C:\mmean과 완전히
  독립된 별도 프로젝트

--------------------------------------------------------------------
2. 절대 원칙 (변경 없이 계속 유지)
--------------------------------------------------------------------
- 자동 주문·매매 기능 없음. 이 시스템은 "지금이 매매 타이밍이다"를
  알려주는 의사결정 보조 도구일 뿐, 실제 매매는 항상 사람이 HTS/MTS에서
  직접 한다
- 회원가입/다중 사용자 시스템 없음, 개인 1인용
- 모바일 웹 우선
