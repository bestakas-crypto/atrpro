역할
----
한국투자증권(KIS) Open API의 TR 스펙 문서를 Excel 형식으로 보관.
코드 구현 시 요청/응답 필드 스펙 확인 참조용. 실행 코드 없음.

주요 파일
---------
선물옵션 주문[v1_국내선물-001].xlsx       주문 TR 스펙
선물옵션 정정취소주문[v1_국내선물-002].xlsx 정정·취소 TR 스펙
선물옵션 잔고현황[v1_국내선물-004].xlsx    잔고 조회 TR 스펙
선물옵션 시세호가[v1_국내선물-007].xlsx    시세·호가 TR 스펙
선물옵션 기간별시세[v1_국내선물-008].xlsx  기간별 시세 TR 스펙
선물옵션 주문체결내역[v1_국내선물-003].xlsx 체결내역 조회 스펙
선물옵션 잔고평가손익내역[v1_국내선물-015].xlsx 손익 평가 스펙
선물옵션 총자산현황[v1_국내선물-014].xlsx  총자산 현황 스펙
선물옵션 분봉조회[v1_국내선물-012].xlsx    분봉 데이터 스펙

실시간 TR (WebSocket)
---------------------
지수선물 실시간체결가[실시간-010].xlsx     H0IFCNT0 체결가
지수선물 실시간호가[실시간-011].xlsx       H0IFASP0 호가
지수옵션 실시간체결가[실시간-014].xlsx     옵션 체결
선물옵션 실시간체결통보[실시간-012].xlsx   H0IFCNI0 체결통보 (주문 계좌)
주식선물 / 주식옵션 관련 실시간 스펙 다수

주식 TR
-------
국내주식 시세 / 호가 / 일자별 / 분봉 등 다수 스펙

참고
----
  - KIS 홈페이지 개발자센터에서 최신 스펙 확인 권장
  - TR 코드 중앙 관리: order/kis_tr_catalog.py (주문) / core/kis_tr_catalog.py (데이터)
