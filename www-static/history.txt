====================================================================
  www.kunoh.top (KUNOH 홈페이지) 배포 히스토리
====================================================================
작성일: 2026-08-06

이 문서는 C:\strpro\www-static\(정적 사이트, www.kunoh.top으로 배포)의
변경 이력을 기록한다. ATRsite-pro 앱 자체의 개발 히스토리는 별도 문서
(C:\strpro\history.txt)에 있고, 이 홈페이지는 완전히 독립된 프로젝트라
따로 관리한다.

이 파일의 용도:
  - www.kunoh.top 전용 변경 이력 기록. ATRsite-pro 앱의 history.txt와
    섞지 않는다.
  - 재배포 절차 문서화. 로컬 수정 -> scp 업로드 -> www-data 소유권
    정리라는 순서를 다음 작업자가 바로 이어받을 수 있게 한다.
  - 의사결정 근거 기록. 예를 들어 Cloudflare Workers 전용 Next.js 원본을
    이 VPS에 그대로 올리지 않고 정적 HTML/CSS로 분리한 이유를 남긴다.
  - Claude/Codex 등 여러 세션과 에이전트 사이의 인수인계 문서 역할.
  - 배포 후 검증 항목(HTTP 200, nginx -t, SHA256 해시 비교)을 남겨
    다음 배포 때도 같은 수준으로 확인하게 한다.
  - ?view=desktop / ?view=mobile 같은 코드 안의 세부 동작을 사람이
    빠르게 읽을 수 있게 설명한다.

배포 구조 요약:
  - 로컬 소스: C:\strpro\www-static\ (index.html/mobile.html/style.css/
    favicon.svg -- JS 없는 순수 정적 페이지)
  - 서버 경로: /var/www/kunoh-home/ (소유자 www-data), nginx가 root로
    직접 정적 서빙(백엔드 프로세스/빌드 스텝 없음)
  - 재배포 절차: 로컬 파일 수정 -> scp로 서버 업로드 -> sudo chown
    www-data:www-data -> 끝(재시작 불필요)
  - VPS/nginx 설정 등 인프라 세부사항은 이 저장소 밖의 세션 메모리에
    있음(strpro_vps_access.md) -- 필요하면 Claude에게 물어볼 것.

[2026-08-03 -- 최초 배포]

원래 로컬에 있던 C:\strpro\www\는 ChatGPT Sites 빌더가 만든 Next.js/
vinext 프로젝트였는데, Cloudflare Workers 전용 바인딩(D1/ASSETS/이미지
최적화)을 써서 이 VPS(순수 nginx, Cloudflare 아님)에는 그대로 올릴 수
없었다. 사용자 확인 후 같은 디자인/문구를 그대로 유지하면서 정적
HTML/CSS로 다시 만들어 C:\strpro\www-static\에 작성(index.html/
style.css/favicon.svg, mailto 링크만 있는 순수 정적 페이지). 원본
Next.js 프로젝트(C:\strpro\www)는 나중에 Cloudflare Pages/Workers로
따로 배포할 가능성을 대비해 로컬에 그대로 보존(삭제 안 함).

/var/www/kunoh-home/에 배포, nginx 설정 신규 작성(/etc/nginx/
sites-available/kunoh-home), www.kunoh.top 전용 인증서 발급.

[2026-08-06 -- 모바일 전용 페이지 분리]

PC 화면 기준으로만 만들어졌던 기존 페이지가 모바일에서 보기 불편하다는
문제로, 모바일 전용 레이아웃을 별도 페이지로 분리함(Codex/GPT 세션에
위임해서 작업, 이 프로젝트의 VPS SSH 접속 정보만 전달하고 실제 작업은
그쪽에서 수행).

변경 내용:
  - index.html: PC용 레이아웃 유지. 모바일 접속을 감지하면(화면폭 +
    터치 포인터 + User-Agent를 종합 판별) mobile.html로 자동 리다이렉트
    하는 스크립트 추가.
  - mobile.html: 신규 작성. 모바일 전용 레이아웃/그래픽 스타일.
  - style.css: 모바일 전용 스타일 규칙 추가(기존 PC 스타일과 공유).
  - 강제 고정 파라미터: PC 버전을 모바일에서도 보려면
    https://www.kunoh.top/?view=desktop, 모바일 버전을 PC에서 보려면
    https://www.kunoh.top/mobile.html?view=mobile

작업 흐름: 로컬(C:\strpro\www-static\)을 먼저 수정한 뒤 서버로 업로드
하는 순서로 진행. 배포 후 다음을 확인:
  - https://www.kunoh.top/             200 OK
  - https://www.kunoh.top/mobile.html  200 OK
  - https://www.kunoh.top/style.css    200 OK
  - nginx -t                           OK(문법 오류 없음)
  - 로컬/서버 파일 SHA256 해시 일치 확인 -> 로컬-서버 동기화 상태 확정.

다음에 이 홈페이지를 다시 작업하기 전에는, 혹시 다른 세션이 서버만
직접 수정했을 가능성에 대비해 로컬(C:\strpro\www-static)과 서버
(/var/www/kunoh-home)의 파일 해시/수정시각을 먼저 비교하는 습관을
유지할 것.

[2026-08-06 -- 브라우저 언어 기반 다국어 페이지 추가]

사용자 요청: OS/브라우저 언어에 따라 홈페이지 언어도 자동 변경되게 하고,
영어 PC면 영어 페이지, 일본어 모바일이면 일본어 모바일 페이지가 뜨도록
구성. 정적 nginx 사이트이므로 서버 사이드 판별이 아니라 브라우저의
navigator.languages / navigator.language와 화면/포인터/User-Agent 기반
기기 판별 스크립트로 처리함.

변경 내용:
  - index.html / mobile.html: 기존 모바일/PC 판별 스크립트를 언어+기기
    통합 라우터로 확장.
  - en.html / en-mobile.html: 영어 PC/모바일 페이지 신규 작성.
  - ja.html / ja-mobile.html: 일본어 PC/모바일 페이지 신규 작성.
  - style.css: 모바일 차트 gradient가 모든 언어 페이지에서 동일하게
    보이도록 mobileChartFill 규칙 보강.

자동 판별 대상:
  - ko-KR 등 한국어: index.html / mobile.html
  - en-US, en-GB 등 영어: en.html / en-mobile.html
  - ja-JP 등 일본어: ja.html / ja-mobile.html
  - 그 외 언어: 한국어를 기본값으로 사용.

강제 고정 파라미터:
  - ?lang=ko / ?lang=en / ?lang=ja
  - ?view=desktop / ?view=mobile
  - 예: https://www.kunoh.top/?lang=en&view=desktop
  - 예: https://www.kunoh.top/ja-mobile.html?lang=ja&view=mobile

배포/검증:
  - 로컬 C:\strpro\www-static\ 수정 후 /var/www/kunoh-home/에 scp 업로드.
  - 배포 파일: index.html, mobile.html, en.html, en-mobile.html,
    ja.html, ja-mobile.html, style.css, favicon.svg.
  - history.txt와 namecard-preview.html은 공개 배포 대상에서 제외.
  - HTTPS HEAD 확인: /, /mobile.html, /en.html, /en-mobile.html,
    /ja.html, /ja-mobile.html, /style.css 모두 200 OK.
  - sudo nginx -t OK.
  - 로컬/서버 SHA256 해시 일치 확인.

[2026-08-07 -- GitHub main 동기화 전 검증]

사용자 요청: VPS에 이미 배포된 www.kunoh.top 다국어 페이지와 자동 판별
코드가 GitHub main에 누락된 상태인지 확인하고, 로컬 C:\strpro\www-static
소스를 기준으로 관련 파일만 커밋/푸시할 준비를 진행.

확인 내용:
  - git remote -v 결과 origin은 https://github.com/bestakas-crypto/atrpro.git.
  - 작업 전 로컬 main HEAD와 origin/main은 모두
    0fb90b153dc946c3ff695a3d138bfe07bc8b9127.
  - origin/main에는 www-static/en.html이 없고, origin/main의
    www-static/history.txt에도 다국어 자동 판별 기록이 아직 없음.
  - 로컬에는 en.html, en-mobile.html, ja.html, ja-mobile.html이 존재.
  - index.html, mobile.html 및 각 언어 페이지에 navigator.languages /
    navigator.language 기반 언어 판별과 화면/포인터/User-Agent 기반
    PC/모바일 판별 코드가 들어 있음.
  - ko-*는 한국어, en-*는 영어, ja-*는 일본어, 그 외 언어는 한국어로
    가는 규칙과 ?lang=ko|en|ja, ?view=desktop|mobile 강제 선택 규칙을
    Node 시뮬레이션으로 확인.
  - HTML 파서로 index.html, mobile.html, en.html, en-mobile.html,
    ja.html, ja-mobile.html의 UTF-8 선언, lang 속성, 내부 링크, CSS/파비콘
    경로를 확인.
  - 6개 페이지 모두 WHAT I BUILD, THE POINT OF AUTOMATION, HOW I WORK,
    START A PROJECT 및 mailto:kuno@kunoh.top 핵심 요소가 존재.

커밋 대상은 www-static의 다국어 페이지/라우터/스타일/기록 파일로 제한하고,
ATRsite-pro 앱 변경, .env, 키, DB, 백업, 로그, 사용자 작업 파일은 포함하지
않는다.
